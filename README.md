# VitaCheck

## Overview

VitaCheck is a Python application developed to calculate a user's Body Mass Index (BMI). The program asks the user to enter their weight and height, validates the input and displays the BMI value together with the corresponding BMI category.

This project was developed as part of a Level 4 Computing module to demonstrate fundamental programming concepts, including user input, input validation, conditional statements and mathematical calculations.

---

## Features

- Calculates Body Mass Index (BMI)
- Validates user input
- Prevents invalid weight and height values
- Displays the BMI value
- Classifies the BMI into one of four categories:
  - Underweight
  - Healthy Weight
  - Overweight
  - Obese
- Simple command-line interface

## How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio Code.
3. Run the `VitaCheck.py` file.
4. Enter your weight in kilograms (kg).
5. Enter your height in metres (m).
6. View your BMI result and category.

## BMI Categories

| BMI Range | Category |
|-----------:|----------------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Healthy Weight |
| 25.0 – 29.9 | Overweight |
| 30.0 and above | Obese |
